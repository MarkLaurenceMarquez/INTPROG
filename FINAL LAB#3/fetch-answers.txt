1. What are the main differences between XMLHttpRequest and Fetch API?

XMLHttpRequest uses callbacks and has a more complex syntax, while Fetch API uses Promises and provides a simpler way to send HTTP requests.

2. Why is the Fetch API considered more modern and readable?

Fetch API is more modern because it uses Promises, has cleaner syntax, and makes asynchronous communication easier to understand and manage.

3. What is the purpose of the .then() and .catch() methods in Fetch?

The .then() method handles successful responses, while the .catch() method handles errors that occur during the request.

4. What happens when you send a POST request to the placeholder API?

The API receives the submitted data and returns a response containing a new post ID. In this example, the returned ID is 101. The post is not permanently saved.
